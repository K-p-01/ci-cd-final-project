# Coursera evidence checklist — capture real outputs only

These artifacts are generated by your actual GitHub/OpenShift environments. They are intentionally not fabricated or prefilled in this repository.

## 1) GitHub Actions terminal output — `cicd-github-validate`

1. Push the repository to GitHub.
2. Open **Actions → CI → the latest run → Lint and unit tests**.
3. Confirm the run and both `Run flake8 lint checks` and `Run nose unit tests` steps are green.
4. Download the workflow logs from GitHub (or copy the real successful job/step output into a plain-text file named exactly `cicd-github-validate`).
5. Keep the actual output, including the run's successful completion. Do not type a made-up success transcript.

## 2) PVC screenshot — `oc-pipelines-console-pvc-details.png`

In the OpenShift web console, select the project used for the pipeline, open **Storage → PersistentVolumeClaims**, then open `oc-pipelines-pvc`. Capture the page where the claim's storage class is `skills-network-learner` and requested capacity is `1Gi`.

## 3) Pipeline definition screenshot — `oc-pipelines-oc-final.png`

In the OpenShift console, open **Pipelines → Pipelines**, select `oc-pipelines-oc-final`, and capture the visible task graph with `cleanup`, `git-clone`, `flake8`, `nose`, `buildah`, and `deploy` / `openshift-client` visible.

## 4) Successful PipelineRun screenshot — `oc-pipelines-oc-green.png`

Open a successful PipelineRun for `oc-pipelines-oc-final`. Capture its green/successful status and the full task sequence. Only use a run that actually succeeded in the cluster.

## 5) Application logs — `oc-pipeline-application-logs`

After deployment, find the running application pod and fetch its logs. For example:

```bash
oc get pods
oc logs deployment/cicd-final-project
```

Save the real output as plain text named exactly `oc-pipeline-application-logs`. It should show `SERVICERUNNING on port 8000` from the application's startup line. If it does not, troubleshoot the deployment rather than adding the expected line manually.

## Suggested final evidence filenames

- `cicd-github-validate` — actual GitHub Actions successful log text
- `oc-pipelines-console-pvc-details.png` — actual OpenShift PVC page
- `oc-pipelines-oc-final.png` — actual OpenShift pipeline definition
- `oc-pipelines-oc-green.png` — actual successful pipeline run
- `oc-pipeline-application-logs` — actual deployed application logs

The grader's upload fields may be separate from the GitHub URL fields. Upload each artifact to the matching field and keep the filename exact.
